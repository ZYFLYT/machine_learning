## 路线1：Pure Python 纯手搓实现
> 无任何矩阵运算库，仅原生list + for循环，8×8手写数字数据集`load_digits`
> 网络结构：64输入 → ReLU隐藏层 → Softmax输出层；逐样本训练
> 内部两个子方案：
> - 子方案1-1：雅可比完整Softmax反向传播（`neuron_jacobi.py` / `train_jacobi.py`）
> - 子方案1-2：Softmax+交叉熵合并梯度简化版（`neuron_standard.py` / `train_standard.py`）

### 子方案1-1：雅可比完整Softmax版本
核心原理：严格链式法则，Softmax单独计算雅可比矩阵，损失函数与softmax分开求导。

反向公式：
$$\displaystyle \frac{\partial L}{\partial Z_j}=\sum_{k}\frac{\partial L}{\partial A_k}\cdot \frac{\partial A_k}{\partial Z_j}$$
嵌套循环显式计算雅可比矩阵乘法。

优点
- 数学完整，完整展示Softmax耦合求导，适合原理学习
- 完全手动控制每一步计算

缺点
- 大量嵌套循环，速度慢，类别越多计算爆炸
- 多次累加带来更大浮点数误差
- 下标极易写错，调试困难

### 子方案1-2：Softmax+交叉熵简化版本
核心原理：交叉熵损失和Softmax合并化简求导，数学上和雅可比等价。

反向公式：
$$\displaystyle \frac{\partial L}{\partial Z}=A-Y$$
直接用`A-Y`作为dZ，跳过雅可比矩阵计算。

### 子方案差异说明
1. **数学等价**：理想实数计算下两套梯度完全一样；
2. 初始loss不同原因：`random.uniform()`随机初始化权重；固定随机种子后第一轮loss基本对齐；
3. 训练过程微小loss差距：雅可比版本循环多次浮点运算，累积舍入误差；
4. 关键知识点：Softmax输出神经元互相耦合，**不能像ReLU/Sigmoid逐元素求导**；`softmax`中`Z-max(Z)`是数值稳定技巧，防止指数溢出。

### 本路线总结
纯手搓适合吃透神经网络前向、反向传播底层公式。
雅可比版本用来搞懂Softmax雅可比矩阵；简化版本是工程上的写法。
缺点：循环极慢，只适合小数据集，不适合大规模训练。

## 路线2：Numpy 向量化实现
> 使用 numpy 数组代替原生 list，矩阵运算代替多层 for 循环；网络结构和上面完全一致：784输入→128隐藏层(ReLU)→64隐藏层(ReLU)→10输出层(Softmax)。
> 同样可以实现两种softmax反向方式（完整雅可比 / 合并A-Y简化版）

### 矩阵维度约定（重点，工业 / 深度学习领域通用）
我们统一约定：
- $m$：batch样本数量，一次输入多少条数据
- $n_{in}$：当前层输入神经元数量
- $n_{out}$：当前层输出神经元数量

1. **权重矩阵 $W$：$[n_{in},\ n_{out}]$**
    - 行：输入维度（上一层神经元）
    - 列：本层输出神经元
    - 公式 $Z = A_{prev} \cdot W + b$
    - $A_{prev}$ 输入：$[m,\ n_{in}]$，每行是**一个样本**
    - $Z$（层输出，激活前）：$[m,\ n_{out}]$，每行是单个样本在本层各个神经元的logit
    - 偏置 $b$：$[1,\ n_{out}]$，广播到整批m个样本，每一列对应一个神经元偏置
> 工业、深度学习工程（PyTorch除外）大量采用这套 `[m, n_in] @ [n_in, n_out] = [m, n_out]` 的布局。
> PyTorch默认权重是`[n_out, n_in]`，只是框架内部存储顺序差异，数学等价。

2. 梯度矩阵
    - $dW$：权重梯度，形状和W完全一致 $[n_{in},n_{out}]$
    - $db$：偏置梯度 $[1,n_{out}]$
    - $dZ$：激活前梯度 $[m,n_{out}]$

### 本路线特点
1. 前向、反向全部用矩阵运算，去掉逐样本for循环，**批量并行计算**，一次性处理m条样本；
2. He / Xavier权重初始化直接作用于numpy矩阵；
3. Softmax使用数值稳定写法 `np.exp(Z - np.max(Z,axis=1,keepdims=True))`，防止exp溢出；
4. 梯度直接矩阵乘法，不再手写多层循环；
5. Softmax+交叉熵采用合并求导简化公式 $dZ = A-Y$，避免显式构造巨大雅可比矩阵，兼顾稳定与速度；
6. **梯度校验**：可以通过数值微分验证手写反向传播的正确性。本次实验梯度检验相对误差 $2.199\times10^{-7}$，通过校验，证明解析梯度实现无误。

### 优点
- 运算速度远高于纯Python手搓；numpy底层C实现，批量计算高效；
- 代码简洁，用矩阵代替大量for循环，下标bug变少；
- 可以直接对照吴恩达课程公式，矩阵维度直观；
- 适合工程入门，是学术界、小型工业项目最常用的手写实现方式。

### 缺点
- 屏蔽了底层单个数字循环的细节；
- 需要理解矩阵维度、广播机制；
- 仍然手动实现前向、反向，手动写梯度，复杂网络代码维护成本高。

### 本路线总结
学习的过渡阶段。保留手动写前向/反向传播，但是利用向量化加速，贴近吴恩达作业标准写法，兼顾原理和性能。

### 踩坑记录（Numpy专项）
1. 损失平均的位置：交叉熵loss除以m做样本平均，**导数只在一处除以m**。如果SoftmaxCrossEntropy.backward和Dense.backward两处同时除以m，梯度会被缩放，梯度检验失败。
2. ReLU缓存：梯度检验多次调用forward，会反复覆盖ReLU内部缓存的`self.Z`，引入微小浮点噪声，造成梯度检验误差轻微抬高。
3. 矩阵形状混淆：区分 `[m,n_out]`（样本放在行）和PyTorch默认`[n_out,n_in]`权重布局，直接照搬容易出现维度不匹配。
4. Softmax数值溢出：必须每行减去该行最大值，不能直接`np.exp(Z)`，大数exp会出现inf。
5. one-hot编码：标签矩阵shape必须和Softmax输出`[m,n_out]`对齐，否则loss计算时报错。

## 路线3：PyTorch框架实现
> 使用PyTorch，网络层、激活函数、损失、优化器全部调用框架API；网络结构保持一致。

### 本路线特点
1. 不用手动写前向传播、反向传播梯度，框架自动微分Autograd；
2. `nn.Linear`、`nn.ReLU`、`nn.Softmax`、`nn.CrossEntropyLoss`直接调用；
3. 内置He/Xavier初始化API；
4. 支持GPU加速。

### 优点
- 开发最快，代码量最少；
- 高度优化，速度最快，支持GPU；
- 成熟稳定，工业项目标准方案。

### 缺点
- 底层梯度计算被框架封装，看不到完整链式求导；
- 不适合理解底层数学推导。

### 本路线总结
工程落地首选。适合训练大规模模型，但是学习底层原理时，必须先经过前面手搓、numpy两个阶段。

## 三大路线横向总结
### Pure Python纯手搓路线
梯度编写：完全手写for循环逐元素计算
底层可见度：⭐⭐⭐⭐⭐ 每一步计算完全可控
运行速度：最慢，多层for循环
代码量：最长，大量循环
适合目标：深度学习底层原理学习
Softmax实现：可实现雅可比完整求导 / A-Y简化版

### Numpy向量化路线
梯度编写：手写矩阵形式前向&反向
底层可见度：⭐⭐⭐⭐ 矩阵运算可见，无底层循环
运行速度：中等，C底层矩阵运算
代码量：中等
适合目标：课程作业，原理+性能平衡
Softmax实现：两种都可以实现，推荐A-Y

### PyTorch框架路线
梯度编写：自动微分，不用手写梯度
底层可见度：⭐⭐ 全部封装，底层不可见
运行速度：最快，可GPU加速
代码量：最短
适合目标：工业项目，快速建模
Softmax实现：框架内置CrossEntropyLoss（内部就是softmax+交叉熵合并）

## 项目踩坑记录
1. `AttributeError: 'DenseLayer' object has no attribute 'W'`
    - 原因：`__init__`初始化函数中，activation="softmax"没有进入分支，没有创建self.W
    - 解决：elif条件加入`softmax`，softmax层使用Xavier初始化

2. W矩阵下标两套体系不要混用
    - jacobi版本W形状`[n_out, n_in]`；standard版本W形状`[n_in, n_out]`，两套内部自洽，不能复制混用

3. Softmax不能逐元素求导！ReLU、sigmoid可以逐元素相乘求导，Softmax是耦合的，需要雅可比矩阵

4. 随机种子：固定`random.seed()`可以消除初始化权重随机带来的初始loss差异
